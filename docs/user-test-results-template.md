## 是否进入下一阶段

满足以下条件时，可以开始准备 V2：

- 至少 3 人中有 2 人能独立开始探索；
- 至少 3 人中有 2 人完成古今对照；
- 至少 3 人中有 2 人找到地名查询；
- 没有人把示意图明确当作现代边界；
- 至少 1 人主动表达复访理由。

如果未满足，先修改引导、层级或文案，不增加地图数量和大规模数据。
