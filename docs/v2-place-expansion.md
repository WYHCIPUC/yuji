## 1. 目标与硬约束

**目标**（创意文档 V2 行）：「地名库扩至 2000+（接入公开历史地名数据集 CHGIS 精华子集）」。

**硬约束（项目红线，违反任意一条即方案无效）：**

| 红线 | 本方案的落实 |
|---|---|
| 叙事止于 1602 年 | 数据层所有年份字段在流水线中硬过滤/clamp 至 ≤1602，并写入 lint 强制校验 |
| 未确认版权不引真实素材 | CHGIS 采用受 EULA 条件约束（§3），人工终审通过前不进入正式发布 |
| 争议考订不写唯一答案 | 数据层条目标注考订来源与单源属性；叙事层维持两说并存；不做唯一断言 |
| 机器核验 ≠ 终审 | 流水线验收含人工抽检 + 核验人签署（M5） |
| AI 内容须人工复核 | 生成数据不直接上线，走 M5 抽检 |

**明确不做的事：** 不再分发 CHGIS 原始数据文件；不接入民国数据（上海交大源仅作调研）；《中国历史地图集》仅内部参考、不产品化；不考虑任何商用场景。

## 3. 数据源与许可决策

### 3.1 主路径：CHGIS V6 时序三件套（县点 + 府点 + 府界）

许可证据链与逐字引文见来源登记表「CHGIS 许可核验记录（2026-10-09）」，资源全貌见[资源全景图](gis-resource-map.md)。三个数据集（county points doi:10.7910/DVN/Q9VOF5、prefecture points doi:10.7910/DVN/WW1PD6、prefecture polygons doi:10.7910/DVN/I0Q7SM）许可口径完全一致：Dataverse 元数据标 CC0 1.0，但条款文本均声明「©哈佛+复旦、学术免费、禁商用/转售/再分发、详见 EULA」。**存在冲突，本项目按更严格的 EULA 口径执行。**

各数据集分工：

| 数据集 | 用途 | 特别口径 |
|---|---|---|
| 县级治所点 | 数据层主体（≤1602 过滤后去重入库） | 点位为概化位置，UI 注明「示意精度」 |
| 府级治所点 | 数据层府级子层；县点稀疏的早期时段（前置 1350）以府级兜底展示高层政区格局 | 同为概化位置 |
| 府级政区多边形 | 地图「政区格局示意层」：MapLibre 按朝代切换的府级色块 | **官方说明多边形系治所点 Voronoi 邻近分配生成，「不是实际行政边界」**——UI 强制标注「示意重绘（邻近分配），非历史实边界，不代表任何现实主张」，与创意文档边界合规要求一致 |

**合规使用四原则（设计约束，逐条对应 EULA 条款）：**

1. **子集而非整体**——只取县级治所点（CHGIS 时序表的空间摘要层）中 ≤1602 年的部分，远非 CHGIS 数据层整体，避开「整体并入公开作品」禁令；
2. **转换而非再分发**——仓库中只出现本项目派生的 JSON，不提交 shapefile/dbf 原始文件，站点不提供任何数据下载，避开「电子形式再分发数据集本身」禁令；
3. **强制署名**——NOTICE 与页面数据来源面板按 EULA 规定格式引用，并逐项说明改动（§8）；
4. **非商业教育用途**——禹迹为免费公开教育叙事站；**未来任何商业化（广告、付费、赞助挂名）之前必须重新核验并可能取得 CHGIS 商业数据许可**，此句写入 NOTICE。

**覆盖缺口如实声明**：官方描述称 1350–1911 年空间覆盖较全、公元前 221–1350 年仍有缺口。对七幕叙事（先秦–明）而言，1350–1602 段（明前中期）覆盖最好，恰是叙事后半；前半段以现有手工精选叙事地名补位，数据层稀疏区在 UI 与报告中如实标注，不用插值伪造密度。

**决策门：**

- **Gate-1（人工）**：负责人审核本方案与许可核验记录，批准主路径。
- **Gate-2（书面确认）**：实施期间向 chgis@fas.harvard.edu 发函，说明「公开免费教育网站展示经筛选、转换之子集（≤1602）并署名」，请求书面确认；30 天无回复 → 按 EULA 字面保守路径继续（仍满足四原则）或转回退路径，由负责人裁决。发函与回函留档进来源登记表。

### 3.2 回退路径：公版正史地理志自建

- **来源**：汉书地理志、后汉书郡国志、晋书地理志、宋书州郡志、南齐书州郡志、魏书地形志、隋书地理志、旧/新唐书地理志、宋史地理志、辽史地理志、金史地理志、元史地理志、明史地理志。正史原文均已入公有领域；所用底本（公版扫描或维基文库文本）仍须逐一登记后使用。
- **纠正一处创意文档表述**：「历史地名大辞典公版内容整理」中的《中国历史地名大辞典》（史为乐主编，2005/2010 年出版）**在著作权保护期内，不是公版**——只能作内部核对参考，不得抄录进产品。特此更正并记录。
- **量级与代价**：预期 800–1200 条（低于 CHGIS 路径），零许可风险，人工整理量大。
- **触发条件**：Gate-1 否决 CHGIS，或 Gate-2 函件得到否定答复，或 CHGIS 数据 ≤1602 去重后数量严重不足且无法满足 2000+ 目标。

## 4. 双层数据架构

| | 叙事层 `places.json` | 数据层 `places-dataset.json` |
|---|---|---|
| 性质 | 手工精选考据条目 | 脚本生成的 CHGIS 派生数据 |
| 维护 | 人工编辑 | **禁止手改**（文件头带生成标记，lint 校验） |
| 驱动 | 七幕叙事、mapPlaces、地图重点标注 | 地名查询扩容检索、朝代治所点层 |
| 考据深度 | 完整（含称谓链条、两说并存） | 精简（名称、年份区间、点位、来源） |

- 查询框同时检索两层：叙事层命中优先展示完整考据，数据层命中展示精简条目。
- 生成时按 `name` 与叙事层去重：叙事层已有名称则数据层跳过，避免双记录；同名不同指（同名异地）由「名称 + 坐标簇」区分，保留多条并在 note 标注。

## 5. 数据层 Schema（v1）

```json
{
  "name": "钱塘",
  "pinyin": "qiantang",
  "level": "县",
  "modern": "浙江省杭州市",
  "lng": 120.16,
  "lat": 30.25,
  "presences": [{ "from": -222, "to": 589 }],
  "certainty": "合理解释",
  "source": "CHGIS V6 时序县级治所点（doi:10.7910/DVN/Q9VOF5）"
}
```

字段约定：

- `level` 为行政层级（`县` / `府`），来自府点数据集的条目标 `府`；查询与点层渲染按层级区分样式。
- `presences[].from/to` 为年份整数，**负数 = 公元前**；`to` 一律 clamp 到 1602（红线）。
- `modern` 为今地对照，仅到省级行政区（Natural Earth admin1 反查）；反查失败写 `"（今地待考）"`，不猜。
- `certainty` 沿用全局枚举（可确定事实 / 合理解释 / 学术争议）；数据层默认 `合理解释`（CHGIS 为学界考订成果，但本项目为单源转引）。
- `lng/lat` 为 WGS84 治所点位；UI 展示须注明「治所点位（示意精度）」。

## 6. 离线流水线（`scripts/expand-places.mjs`，新增）

```
原始 zip ×3（人工一次性下载，不入库）：县点 / 府点 / 府界多边形
  └─ pyshp（MIT 许可）本地导出 TSV/简化 GeoJSON：name_ft / name_py / pres_year / obj_type / 坐标
  └─ 字段语义与 obj_type 编码依据：V6 Data Dictionary（doi:10.7910/DVN/SNCEAU）
       └─ expand-places.mjs
            1) 过滤：pres_year ≤ 1602；名称非空；坐标落在中国粗框 [73,18]–[135,54]
            2) 去重：同 name_ft 且坐标相距 <0.5° 视为同一治所；合并年份区间
            3) 叙事层去重：places.json 已有名称跳过
            4) 今地反查：Natural Earth admin1 预生成空间索引 → modern 省级
            5) 府界多边形：简化坐标（Douglas-Peucker，阈值 ~0.02°）→ public/geo/hist-pref/{era}.json
            6) 产出：src/content/places-dataset.json + public/geo/hist-pref/ + docs/expand-report.md
```

- 原始下载物放 `release/_tmp/`（已 gitignore），**任何 CHGIS 原始文件不得进入仓库与 public/**（府界产出为简化转换后的派生 GeoJSON，属「转换」而非「再分发」，并带署名）。
- `expand-report.md` 内容：条目总数、县/府分布、朝代分布、覆盖缺口说明、去重统计——达没达到 2000+ 以此报告为准，如实记录。
- 数量预期：去重后 2000+；**若实际不足，先上线实际量级并在报告与 README 如实标注，同时启动回退路径补齐**（不虚报、不硬凑）。

## 7. `scripts/lint-content.mjs` 扩展

新增数据层校验（与现有叙事层规则并列，任何一条 fail 即 `npm run verify` 失败）：

1. 文件头含生成标记（防手改）；
2. 必填字段齐全；`level` 在枚举（县/府）内；`certainty` 在枚举内；`source` 以 `CHGIS V6` 开头；
3. 坐标在中国粗框范围内；
4. **`presences` 非空且所有 `to ≤ 1602`（红线硬校验）**；
5. 名称唯一性：同名条目必须坐标可区分；
6. `expand-report.md` 存在；条数 <2000 时输出 warn（不 fail，配合如实标注策略）；
7. `public/geo/hist-pref/` 各朝代文件含 `"disclaimer"` 字段（示意重绘声明），缺失即 fail。

## 10. 风险与对策

| 风险 | 对策 |
|---|---|
| CC0 元数据与 EULA 冲突 | 按更严格 EULA 执行；Gate-2 书面确认兜底 |
| 府界多边形是 Voronoi 示意区划、非真实历史边界 | UI 强制标注「示意重绘，非历史实边界，不代表任何现实主张」；lint 校验声明字段存在 |

| 治所坐标精度有限（概化点位） | UI 注明「示意精度」；不用于精确叠图断言 |
| 今地反查错漏 | 只到省级；失败标「今地待考」 |

| 未来商业化误用 | NOTICE 与本文档明文：商业化前必须重取许可 |
| 实际数量不足 2000+ | 如实标注实际上线量级，启动回退路径补齐，不硬凑数字 |
