# 来源登记表

正式发布前，每条图片、文字、字体和音频都要补齐以下字段：

| 字段 | 说明 |
|---|---|
| 内容名称 | 文件或内容的明确名称 |
| 内容类型 | 图片、文字、字体、音频、数据 |
| 原始链接 | 内容所在的机构或作者页面 |
| 收藏机构/作者 | 资料的实际提供方 |
| 访问日期 | 最近一次查看日期 |
| 许可类型 | 公版、CC许可、机构授权或待核验 |
| 是否可修改 | 是否允许裁切、配准和颜色处理 |
| 是否可公开发布 | 是否可以放到公开网站 |
| 是否需要署名 | 页面需要如何署名 |
| 使用位置 | 具体页面或文件 |
| 核验人 | 谁做了人工确认 |
| 备注 | 争议、限制和后续动作 |

当前原型中的古图和部分文字仍是演示数据，状态为“待核验”或“需人工复核”。

## 古地图候选来源核验清单（第一轮研究，2026-10-06）

本轮研究的目标：为创意文档规划的四幅古地图定位候选数字来源，把“版权核验”从待办变成可点开的清单。

**通用结论（本轮已确认的判断基础）：**

1. 四幅原图本体均完成于 1602 年或以前，著作权已消灭，属公有领域。**风险不在原图，而在现代扫描件/照片的权属和各数据库的下载条款。**
2. 美国判例传统（Bridgeman Art Library v. Corel, 1999）下，对公版二维艺术品的忠实扫描通常不产生新版权；美国机构（如国会图书馆）的扫描件多数标注“无已知限制”，采用风险最低。
3. 欧洲机构可能对扫描件主张数据库权利或以网站条款设限，需逐幅查看下载页条款。
4. 拓片照片的权利取决于拍摄/扫描者的授权声明（如维基共享资源文件页的许可标签），使用前必须核对标签并按要求署名。

**本轮机器核验受阻说明：** 2026-10-06 当日所有联网核验通道不可用（检索配额耗尽至 10-08、国会图书馆拒绝自动访问、维基媒体连接超时）。下表“状态”均为“已定位、待人工点开确认”；配额恢复后可先由助手重试自动核验，再由核验人终审。
