# 原型测试记录

## 测试目标

验证用户是否能在不接受口头解释的情况下完成：

1. 进入页面并开始探索；
2. 拖动时间轴；
3. 打开古今对照；
4. 拖动透明度滑杆；
5. 查询一个地名；
6. 找到来源与说明。

时间轴同时支持点击时代节点、鼠标拖动和触摸拖动；测试时三种方式任选其一即可。

## 建议记录字段

| 字段 | 记录方式 |
|---|---|
| 测试设备 | 手机型号或电脑浏览器 |
| 完成主流程时间 | 从打开到完成地名查询 |
| 第一次点击 | 用户没有提示时点击了什么 |
| 卡住的位置 | 用户停顿、反复点击或询问的地方 |
| 用户复述 | 用户如何描述自己看到了什么 |
| 误解 | 是否把示意图当成现实边界或精确数据 |
| 最喜欢的内容 | 用户主动提到的部分 |
| 最想继续看的内容 | 用户提出的下一步需求 |
| 修正优先级 | 高、中、低 |

## 通过条件

- 至少 3 名非开发用户参与；
- 至少 80% 用户能独立完成主流程；
- 用户能说出时间轴表达的是“天下观变化”；
- 用户知道古图叠层是示意并能找到来源说明；
- 移动端没有无法完成的核心操作。
