# 非开发用户试用脚本

## 组织方式

- 每次只邀请 1 名测试者；
- 尽量使用测试者自己的手机或电脑；
- 开始前不要解释“时间轴”或“古今对照”；
- 只在测试者连续 20 秒没有操作时提醒“你可以继续看看”；
- 不评价测试者的操作对错。

## 开场话术

“这是一个关于古代地图和天下观的网页。请你像平时浏览网页一样使用它，边看边说出你在想什么。”

## 任务

1. 你觉得这个页面要你做什么？请先自己开始。
2. 请找到 1136 年，并说说你注意到了什么变化。
3. 请打开一个可以比较古图和今天地图的功能。
4. 请把古图透明度调到你能看清两层的位置。
5. 请查询“燕京”或你熟悉的地名。
6. 请找到这个项目的来源和说明。

## 记录重点

- 是否在 30 秒内发现时间轴；
- 是否知道时代节点可以点击；
- 是否理解“掀开古今对照”的含义；
- 是否把示意图当成精确地图；
- 是否能找到地名查询；
- 哪个内容让测试者主动停留；
- 测试者主动提出了什么想继续看的内容。

## 结束提问

1. 你觉得这个项目最有价值的地方是什么？
2. 哪一步最困惑？
3. 你愿意把它发给谁？为什么？
4. 你最想查哪个地方或哪个时代？

## 通过门槛

- 3 名测试者中至少 2 名能独立开始探索；
- 3 名测试者中至少 2 名能完成古今对照；
- 3 名测试者中至少 2 名能找到地名查询；
- 没有测试者把示意边界明确当作现代边界；
- 至少 1 名测试者主动表达复访理由。
