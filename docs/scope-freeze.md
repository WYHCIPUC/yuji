# 第一版范围冻结

更新时间：2026-10-03

## 本版必须完成

- 三个时代节点：商周、1136 年、1602 年；
- 时间轴拖动、点击、播放、暂停、重置；
- 一个古图与现代灰模叠层示意；
- 透明度滑杆；
- 一位制图者故事卡；
- 20 条地名查询；
- 五服和郡县两个示意模型；
- 来源说明和不确定性标记；
- 移动端和电脑端适配；
- 减少动画模式。

## 明确推迟

- 7 个时代；
- 4 幅古地图；
- 200 条以上地名；
- 河流改道和郑和针路；
- 分享卡；
- 账号、收藏、社区、支付和后台；
- MapLibre、实时 API 和数据库。

## 发布红线

1. 没有明确来源和许可的图片不能作为正式素材发布。
2. 示意边界必须标注“示意重绘，不代表现实边界主张”。
3. AI生成的历史内容必须人工复核。
4. 不能把有争议的地名考订写成唯一答案。
