# 发布前检查清单

## 代码和构建

- [ ] `npm install` 成功；
- [ ] `npm run build` 成功；
- [ ] `npm run verify` 成功；
- [ ] `npm run preview` 后首页返回 200；
- [ ] 移动端和电脑端各打开一次；
- [ ] 浏览器控制台没有阻断核心流程的错误。

## 内容和来源

- [ ] 所有正式图片都有许可记录；
- [ ] 所有字体和音频都有许可记录；
- [ ] 人物独白已经人工复核；
- [ ] 地名表中的争议已标记；
- [ ] 示意边界旁有明确说明；
- [ ] “待核验”内容不会被误认为正式史实。

## 体验

- [ ] 首次打开后 30 秒内能理解下一步；
- [ ] 60 秒内可以完成时间轴和古今对照；
- [ ] 地名无结果时有解释；
- [ ] 古图加载失败时仍可浏览；
- [ ] 减少动画模式可用；
- [ ] 默认没有自动播放声音。

## 发布方式

- [ ] 确认 GitHub 仓库为目标仓库；
- [ ] 确认默认分支名称为 `main`；
- [ ] GitHub Pages 来源设置为 GitHub Actions；
- [ ] 推送后检查 Actions 构建日志；
- [ ] 打开线上地址并再次完成主流程；
- [ ] 保存线上版本号和发布日期。
